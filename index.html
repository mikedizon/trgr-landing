How an engagement runs

  1. Scoping Your system, your data flows, your timeline, and which authorization path fits. This is the consultation, and it is where pricing is scoped.
  2. Boundary and architecture The authorization boundary drawn to match what you actually run, and the GovCloud architecture that implements it.
  3. Build The environment stood up as code: accounts, network, identity, logging, encryption, and the controls the framework requires.
  4. Package and assessment The system security documentation written from the system as built, and support through the assessment that follows.
